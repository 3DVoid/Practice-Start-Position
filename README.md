## Installation
- Install [Geode](https://geode-sdk.org/install) through [GitHub](https://github.com/geode-sdk/geode) or [Their Official Website](https://geode-sdk.org/install)
- Open Geometry Dash
- Press the Geode Button
- Press Download and Search "Practice Start Positions"
- Hit "View" and Press Install
- Done!
